Hand Tracking with MediaPipe ✋

A Python computer vision project that uses OpenCV and MediaPipe to detect and track hand landmarks in real time using a webcam.

✨ Features

* Detect up to two hands.
* Track hand landmarks in real time.
* Identify the five fingertips.
* Display fingertip names on the screen.
* Draw hand connections and landmarks.
* Use the webcam for live hand tracking.

🛠️ Technologies

* Python
* OpenCV
* MediaPipe
* Computer Vision
* Webcam

🚀 How to Use

1. Install the required libraries.
2. Run the Python program.
3. Allow access to the webcam.
4. Show your hand in front of the camera.
5. The program detects and displays the hand landmarks.
6. Press Q to exit.
